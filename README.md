# Physics for Quantum Computing
## Skill Assessment – 2 (SA-2)

### Program: Quantum Circuit Using X and H Gates

This repository contains the Python program provided for Skill Assessment – 2 in the **Physics for Quantum Computing** course.

### Software Requirements

- Python
- Qiskit
- Qiskit Aer
- Matplotlib
- NumPy
- Jupyter Notebook or Google Colab

### How to Execute the Program

1. Open the supplied `Copy of SA-2 25-26 sample X Gate.ipynb` notebook in Jupyter Notebook or Google Colab.
2. Run the notebook cells in the given order.
3. Allow the installation cells to complete.
4. Observe the circuit diagrams and the outputs generated by the program.

### Program Execution and Observations

The supplied program:

1. Installs the required Python packages.
2. Displays the installed Qiskit and Qiskit Aer versions.
3. Creates a two-qubit quantum circuit and applies the X gate to the first qubit.
4. Calculates and displays the initial statevector and probability values.
5. Displays the Bloch sphere representation.
6. Displays the quantum circuit.
7. Simulates the state and displays the measurement histogram for 1000 shots.
8. Applies the H and X gates in the sequence provided in the notebook.
9. Displays the updated quantum circuit.
10. Calculates and displays the final statevector.
11. Displays the final measurement histogram for 1000 shots.

### Student Instructions

- Execute the supplied notebook cells in sequence.
- Observe the quantum circuit diagrams.
- Observe the initial and final statevectors.
- Observe the Bloch sphere representation and measurement histograms.

Submit the completed Jupyter Notebook (`.ipynb`) with the executed outputs through the submission method specified by the course instructor.
